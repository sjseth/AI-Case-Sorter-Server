This folder should contain your trained models. In the AI Case Sorter application, these are the files which are in the training/models  folder and are typically .zip files.  In actuality, these should be .pth files but I named them as zip since that is really what they are...and I am weird that way. 

Do not place a Model export zip in this folder as that is a different format, (still zip but contains manifest and images which is not what this server needs and will not work).
